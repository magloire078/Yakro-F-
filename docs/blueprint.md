# **App Name**: Yakro Go

## Core Features:

- Location-Based Search: Allow users to search for nearby restaurants and supermarkets based on geolocation.
- Menu/Product Display: Display menus and product details including descriptions, images, and prices.
- Customizable Shopping Cart: Enable users to add items to a cart and customize orders with options and add-ons.
- Real-Time Order Tracking: Provide real-time order status updates, from order placement to delivery.
- Personalized Recommendations: Generate personalized recommendations for restaurants, meals, or items to streamline the ordering experience. This is an AI tool.
- Order history: Display past orders and saved information, allowing customers to quickly reorder favorite meals or items

## Style Guidelines:

- Primary color: Vibrant orange (#FF8C00) to convey energy and enthusiasm.
- Background color: Light peach (#FAEBD7), a very desaturated near-analog of orange, creating a warm, inviting backdrop.
- Accent color: Soft yellow (#F0E68C) to complement the orange, for a cheerful highlight.
- Headline font: 'Belleza' (sans-serif), best suited to artistic content or short texts.
- Body font: 'Alegreya' (serif) is chosen to pair with Belleza to display blocks of text
- Use clean, modern icons related to food, delivery, and navigation. Icons should be in the primary orange color.
- Ensure a grid-based layout to organize content effectively.
- Incorporate subtle transition animations when updating the order status or displaying recommendations.
