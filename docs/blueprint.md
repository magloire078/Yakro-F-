# **App Name**: Yakro Fê

> Le design system de référence est documenté dans `AGENTS.md` à la racine
> ("Yakro Elite"). Ce fichier conserve la liste fonctionnelle d'origine.

## Core Features

- Location-Based Search: Allow users to search for nearby restaurants and supermarkets based on geolocation.
- Menu/Product Display: Display menus and product details including descriptions, images, and prices.
- Customizable Shopping Cart: Enable users to add items to a cart and customize orders with options and add-ons.
- Real-Time Order Tracking: Provide real-time order status updates, from order placement to delivery.
- Personalized Recommendations: AI-generated recommendations for restaurants, meals, or items.
- Order History: Display past orders and saved information for quick reordering.

## Style Guidelines

Le design "Yakro Elite" actuel (cf. `AGENTS.md`) :

- **Primary** : Orange-500 `#F97316` (CTA, accents).
- **Background** : Deep dark `#0A0A0B` / Slate-950.
- **Containers** : Glassmorphism (`backdrop-blur-xl`, bordures `border-white/5`).
- **Typography** : Sora / Inter, gros titres `font-black uppercase tracking-wide`, italiques accentués.
- **Animations** : `animate-slow-zoom`, `animate-float`, entrées `fade-in slide-in-from-bottom-4`.

Polices héritées (toujours chargées dans `src/app/fonts.ts`) : Belleza (titres
décoratifs), Alegreya (corps long), Sora (UI principale).
