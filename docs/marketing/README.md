# Marketing — Plan Yakro Fê

Documents opérationnels pour le lancement de Yakro Fê, structurés par
phase. Le tout couvre **90 jours**, de la première signature restaurant
jusqu'au lancement grand public.

## Vue d'ensemble

| Phase | Période | Focus | Statut |
|---|---|---|---|
| **Phase 0** — Acquisition restaurateurs | Sem. 1-4 | Signer 15-20 restos quality-first | Voir docs ci-dessous |
| **Phase 1** — Soft launch | Sem. 5-8 | Beta fermée 200-300 early adopters | Voir docs ci-dessous |
| **Phase 2** — Lancement grand public | Sem. 9-12 | Campagne hyper-locale (radio, géofencing, ambassadeurs) | À rédiger après Phase 1 |

---

## Phase 0 — Acquisition restaurateurs

| Fichier | Usage |
|---|---|
| [`plaquette-commerciale-brief.md`](./plaquette-commerciale-brief.md) | Brief texte à donner à un graphiste pour la plaquette A4 5 pages |
| [`contrat-partenariat-restaurant.md`](./contrat-partenariat-restaurant.md) | Modèle de contrat type (à valider par un juriste avant signature) |
| [`emails-relance.md`](./emails-relance.md) | 3 variantes de relance (RDV reporté, objections, dernière chance) |
| [`onboarding-restaurant.md`](./onboarding-restaurant.md) | Check-list 90 min pour intégrer un nouveau resto sur la plateforme |

**Cibles** :
- *Cercle 1 — "Phares"* (5, sem. 1-2) : restos d'hôtels, grandes tables locales, cuisine internationale.
- *Cercle 2 — "Volumes"* (10, sem. 2-3) : maquis chics, pizzerias, pâtisseries.
- *Cercle 3 — "Fidèles"* (5, sem. 4) : petits restos de quartier sans présence digitale.

**KPIs** :
- 15-20 contrats signés à J+30
- 60-100 plats au catalogue
- Photos pro pour le top 10
- 5 "Restaurants Fondateurs" badgés en exclu

## Phase 1 — Soft launch

| Fichier | Usage |
|---|---|
| [`strategie-invitation-beta.md`](./strategie-invitation-beta.md) | Segmentation des 200-300 invités + calendrier d'invitation + mécanique de parrainage |
| [`whatsapp-scripts.md`](./whatsapp-scripts.md) | 10+ modèles de messages prêts à envoyer (premier contact, relance, feedback, crise) |
| [`calendrier-social-soft-launch.md`](./calendrier-social-soft-launch.md) | Planning jour par jour des posts IG/FB/WhatsApp Status de J-7 à J+7 |
| [`feedback-beta.md`](./feedback-beta.md) | Collecte (3 canaux), triage hebdo, KPI, critère go/no-go pour Phase 2 |

**Segments** :
- *Segment A* (50, sem. 5) : cercle privé (famille, amis, clients restos).
- *Segment B* (50, sem. 6) : influence locale (bloggers, campus, hôtels, expats).
- *Segment C* (150-200, sem. 7-8) : parrainage via codes.

**KPIs** :
- 300 inscrits à J+56
- Note moyenne in-app ≥ 4.2 / 5
- NPS ≥ 40
- Taux de complétion commande ≥ 90%
- Top 3 plaintes récurrentes adressées

---

## Règles de décision entre phases

- **Phase 0 → Phase 1** : ne pas lancer Phase 1 sans 15 restos signés + photos pro top 10.
- **Phase 1 → Phase 2** : ne pas lancer Phase 2 si NPS < 40 ou complétion < 90% — prolonger Phase 1 de 2 semaines.

Un mauvais lancement à Yamoussoukro se paye en heures via WhatsApp et
en mois de réputation. Mieux vaut être en retard que mauvais.
