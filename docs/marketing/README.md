# Marketing — Phase 0 (Acquisition restaurateurs)

Documents opérationnels pour la phase 0 du lancement Yakro Fê : signer
15 à 20 restaurateurs avant l'ouverture grand public.

| Fichier | Usage |
|---|---|
| [`plaquette-commerciale-brief.md`](./plaquette-commerciale-brief.md) | Brief texte à donner à un graphiste pour la plaquette A4 5 pages |
| [`contrat-partenariat-restaurant.md`](./contrat-partenariat-restaurant.md) | Modèle de contrat type (à valider par un juriste avant signature) |
| [`emails-relance.md`](./emails-relance.md) | 3 variantes de relance (RDV reporté, objections, dernière chance) |
| [`onboarding-restaurant.md`](./onboarding-restaurant.md) | Check-list 90 min pour intégrer un nouveau resto sur la plateforme |

## Cibles Phase 0

- **Cercle 1 — "Phares" (5 cibles, sem. 1-2)** : restos d'hôtels (Président, Akwaba, Parlementaires), 2-3 grandes tables locales, 1 cuisine internationale tendance.
- **Cercle 2 — "Volumes" (10 cibles, sem. 2-3)** : maquis chics, pizzerias / fast-food locaux, pâtisseries.
- **Cercle 3 — "Fidèles" (5 cibles, sem. 4)** : petits restos de quartier sans présence digitale.

## KPIs

- 15-20 contrats signés à J+30
- 60-100 plats au catalogue
- Photos pro pour le top 10
- 5 "Restaurants Fondateurs" badgés en exclu

Si ces seuils ne sont pas atteints à J+30, **prolonger Phase 0 de 2
semaines** plutôt que d'enchaîner sur Phase 1 (soft launch) avec une
offre trop maigre.
